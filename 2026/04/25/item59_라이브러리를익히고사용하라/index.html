아이템 59. 라이브러리를 익히고 사용하라

- 예시에서는 Random 클래스를 활용한 난수 생성 메소드를 구현하고 그것을 사용하는데 있어, 몇가지 문제가 발생함을 경고한다.

  • 같은 수열이 반복되거나,
  • 몇몇 숫자가 자주 등장하거나,
  • 확률상 수의 분포가 고르지 않거나 이다.

단순히 Random() 함수 사용을 경고하는게 아니라, 가급적 많은 문제를 선도적으로 해결한 라이브러리를 사용할 것을 권장함.

  • ThreadLocalRandom 을 사용하여, 속도도 빠르고 더 랜덤한 값을 얻는다.

- 아래의 이유로 라이브러리 사용을 권장한다.

  • 시간을 허비하지 말자. 잘 만들어진 라이브라리를 잘 찾아서 사용하고, 기능개발에 집중해라.
  • 라이브러리는 지속적으로 성능이 개선된다.
  • 심지어 기능이 점점 많아지기도 한다.
  • 내 코드가 다른 이들에게 더 낮익고 익숙한 코드가 된다.

- 최소한 아래의 JAVA의 패키지들은 익숙해져라

  • java.lang
  • java.util
  • java.io
  • java.util.concurrent item80, item81

- java 고유 라이브러리에 익숙해지고, 없다면 third-party 라이브러리에도 관심 가져라 Guava 등등..
