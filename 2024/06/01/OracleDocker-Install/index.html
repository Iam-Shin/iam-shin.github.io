Oracle Docker Install

우분투에 도커로 오라클 설치

0. 도커 설치

1. 우선 참고

  1. 도커 오라클 최초 설정 참고 (블로그)
  • [블로그 soir1984] (https://soir1984.tistory.com/84)
  • [블로그 nataekoon] (https://nataekoon.tistory.com/149)
  1. 도커 허브 접속하여 설명 확인
  • https://dockerhub.com
  • search 창에 oracleinanutshell/oracle-xe-11g 찾으면 설명 나옴.

2. 우분투에서 오라클 최초 설치.

  1. 도커 이미지 다운로드 해서 기본실행까지 (내부 오라클 폴더 확인위해 임시실행)

3. 오라클 데이터폴더를 컨테이너 내부에서 OS디렉토리로 연결(데이터 영속성)

5. dbeaver, sql developer 등 DB 클라이언트 프로그램에서 접속 확인.

  • 접속 확인후 DB에 테이블 생성, 데이터 변경등 변경 발생 시킴.(중요!!)

6. 오라클 컨테이너 껏다 켜면서 DB 확인.

7. 컨테이너 재시작 되어도 데이터 영속성 확인.

8. 생성한 oracleimg 컨테이너 삭제.

(참고) 도커 컨테이너 명령.

  • docker run은 도커 컨테이너 신규 생성.
  • docker start/restart는 이미 생성한 컨테이너 시작/재시작
